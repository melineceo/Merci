# Не участвует в сборке

Здесь лежит правка к чужому проекту, найденная, пока Merci умела запускать
APK внутри себя через ATL. Этот путь убран, и патч ничего не собирает — он
сохранён, потому что чинит настоящую ошибку в
[bionic_translation](https://gitlab.com/android_translation_layer/bionic_translation)
и его стоит отправить авторам.

`recursive-dl-lock.patch` — линковщик держит **нерекурсивный** мьютекс на
`dlopen`/`dlsym`, а конструкторы загружаемой библиотеки вызываются, пока
замок ещё удерживается. Библиотеке никто не запрещает позвать `dlopen`
оттуда — в настоящем Android этот замок рекурсивный именно поэтому. Любое
приложение, которое так делает (`libroblox.so` — делает), вешает процесс
намертво: главный поток ждёт замок, который держит сам.
